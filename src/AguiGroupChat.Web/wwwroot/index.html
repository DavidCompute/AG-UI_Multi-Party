❓ 使用帮助

🚀 快速上手

  • 登录 / 注册：注册新账号或登录已有账号；勾选「保持登录状态」后，除非退出登录，否则下次访问无需再次登录
  • 创建知聚：左侧「我的知聚」点 ＋，填写知聚名并勾选成员（可勾选数字员工一起加入知聚）
  • 发送消息：底部输入框输入，Enter 发送、Shift+Enter 换行；发送前可选可见范围
  • 刷新：知聚列表 / 成员列表标题栏的 🔄 按钮可重新拉取最新数据（与创建知聚 / 添加成员按钮并排）

🔒 知聚管理

  • 私密知聚：创建知聚时可勾选「🔒 私密知聚」。私密知聚的聊天记忆仅限本知聚内检索，数字员工在其他知聚触发时不会读到私密知聚内容
  • 知聚设置：聊天区右上角 ⚙ 按钮，可修改知聚名 / 头像 / 私密开关，并解散知聚（仅知聚主可操作，解散后聊天与记忆一并清除）
  • 移除成员：知聚主 / 管理员可在成员列表点击成员行右侧 ✕ 移除（不能移除知聚主；数字员工 / 分身同样可移除）
  • 知聚主显示：聊天区头部显示知聚主昵称（无昵称时显示用户名）

🤖 数字员工与触发

  • @ 触发：双击成员列表中的成员（再次双击取消），被 @ 的行会高亮，输入框上方出现 @ 标签
  • @ 全体：点输入框上方的「@全体」按钮
  • 触发方式（角色默认）：@ 提及触发 / 👁 全量监听 / # 关键词触发 / 🧠 语境触发，成员列表中以图标显示
  • 知聚内覆盖：数字员工成员行右侧 ⚙ 按钮，可单独设置该数字员工在本知聚的触发方式（覆盖角色默认）
  • 语义记忆（RAG）：聊天记录向量化存入 PostgreSQL（pgvector），数字员工回复前自动检索相关历史记忆注入上下文；私密知聚内容自动隔离
  • 个人记忆：数字员工可开启「🧠 个人记忆」，回复时参考触发者本人的历史发言（需触发者用户也开启）
  • 人机交互（审批）：数字员工执行需审批的操作（如发布公告）时，聊天区出现 🔐 交互卡片——仅发起请求的您可点「批准 / 拒绝」，其他成员只能看到等待状态；决策后数字员工继续回复
  • 数字员工自建技能：让数字员工「创建技能 xxx + 人设」→ 🔐 审批卡片 → 批准后自动生成可复用的子数字员工技能（下一条消息生效）；自建技能与手动配置的技能同样可被调用
  • 回复不回显 @：数字员工回复不携带 @ 信息
  • 示例：@需求助手 帮我生成 V2 大纲

💬 消息能力

  • Markdown 渲染：标题、列表、表格、代码块、引用、加粗、行内代码 等均支持，发送与回复都实时渲染
  • 附件上传：点 📎 选择文件，单次最多 9 个、单个 ≤ 20 MB；支持 Word / Excel / PPT / PDF / 文本类附件，服务端自动提取内容供数字员工阅读；图片显示缩略图，其他文件显示下载卡片
  • 长消息：超长内容默认折叠，点「更多 ▾」展开、「收起 ▴」折叠
  • 撤回消息：悬停某条消息，点 🚫 撤回（本人消息或知聚主 / 管理员可撤回任意消息；撤回后内容对所有人隐藏，并清除其语义记忆）
  • 历史记录：滚动到聊天顶部，点「⬆ 加载更早消息」翻页加载更早的消息
  • 话题：聊天区顶部可切换话题或「＋ 新建话题」；悬停某条发言点 💬 可以此消息新建话题（该发言自动迁入新话题作为讨论起点）；话题右侧 🗑 可删除话题（创建者或知聚主 / 管理员，其下聊天记录与记忆一并删除）
  • 🔗 链接代理：数字员工回复中的链接（含内网地址，如外部 AG-UI 专家返回的本地服务）由后端代访——点击后打开经 Hub 代理的页面，无需担心浏览器无法直连 / 混合内容被拦截；下载类链接自动使用正确文件名
  • 🧠 思考过程：外部 AG-UI 专家的「思考」独立展示为可折叠的灰底块（流式中展开实时可见，结束后自动收起），与正文分离
  • 🔧 工具调用：数字员工执行工具时显示「🔧 名称 调用中…」进度行，完成后自动收起，不打扰阅读

🧩 AI 角色管理

  • 入口：顶栏「🤖 数字员工」，可新增 / 编辑 / 删除角色（删除为行内两步确认），支持搜索
  • 角色设定：昵称、头像、Agent ID、一句话简介、Instructions（系统提示词，定义身份 / 职责 / 回复风格）、模型
  • 🧩 技能（Skills）：可把其他数字员工挂为本角色的可调用技能（数字员工间调用）——配置技能标识、描述与目标数字员工后，模型需要该领域信息时会自动调起子数字员工并引用其答复；目标数字员工可为 AG-UI 桥接的外部专家
  • 触发与模型：触发方式（提及 / 全量 / 关键词 / 语境）、模型（默认 deepseek-chat）
  • 🧠 个人记忆：开启后回复时参考触发者历史发言（默认关闭）
  • 🔒 私密数字员工：开启后仅创建者可看到、拉进知聚、编辑与删除，其他用户无法使用
  • 导出 / 导入：工具栏 📥 导入 / 📤 导出全部；每行操作列（📤 导出 / ✏️ 编辑 / 🗑️ 删除图标按钮）也可单独操作；配置以 JSON 文件交换（敏感令牌与归属不导出，导入后归属当前用户）
  • AG-UI 桥接（外部专家）：填写 http(s):// 或 ws(s):// 端点后，该角色不再调用本地大模型，消息经 AG-UI 协议转发给外部服务，其流式回复回灌知聚

👤 账号与资料

  • 右上角账户菜单：修改资料（昵称 / 头像 / 个人记忆）、修改密码、模型配置、数据备份、退出登录
  • 保持登录：登录时可勾选「保持登录状态」，除非退出登录，否则下次访问无需再次登录
  • 界面风格：顶栏 ☀️ / 🌙 按钮切换深色 / 浅色风格，选择会被记住
  • 记忆：系统会记住您最后选择的知聚（再次登录自动进入）与每个知聚最近使用的话题（再次进入该知聚自动选中）
  • 用户与数字员工均支持上传头像（jpg / png / gif / webp，建议正方形）；上传后立即预览，保存后同步到顶栏与各知聚
  • 🧠 个人记忆（默认关闭）：开启后，数字员工回复您时会参考您在其他对话中的历史发言；关闭时您的发言不会被作为个人记忆读取
  • 🪞 AI 分身：修改资料 → 「AI 分身」区。启用后系统根据您在公开知聚的发言生成人设，以分身加入您所在全部公开知聚；可设定触发方式（提及 / 语境 / 全量 / 关键词）并随时修改；同步到公开知聚可补齐新建的知聚；停用即分身退出全部知聚
  • 分身与在线状态：您在线时成员列表显示您本人、分身暂停回复；您离线时分身接管（成员列表显示 🪞 分身、隐藏您本人）
  • 在线召唤分身：即使在线，您在知聚里 @ 自己（提及自己的名字）即可让分身立即回答（需分身已启用且在本知聚）

⚙ 模型配置

  • 账户菜单 → 模型配置：填写 DeepSeek 的 Endpoint 与 API Key
  • Endpoint 留空 → 使用官方端点 https://api.deepseek.com；API Key 留空 → 使用环境变量（DEEPSEEK_API_KEY / OPENAI_API_KEY）
  • 保存后立即生效（无需重启）并持久化；API Key 不回显，只提示是否已配置
  • 首次进入系统且未配置过模型时，会自动弹出配置界面

🧠 记忆管理

  • 账户菜单 → 记忆管理：可视化浏览数字员工的语义记忆（各知聚条数统计、按知聚 / 关键词搜索）
  • 分级：每条记忆可设 普通 / 重要 / 关键——同相似度下重要记忆优先被检索注入回复，关键决策建议升级
  • 自动遗忘：系统按配置的保留天数自动清理过期记忆（普通记忆到期后不再被检索并物理删除）；也可手动遗忘——按知聚保留最近 7/30/90 天或立即遗忘
  • 删除：单条记忆可物理删除（撤回消息、清空话题同样会清除对应记忆）
  • 权限：只能查看 / 治理自己所在知聚的记忆，私密知聚记忆仅本知聚成员可见

📦 数据备份

  • 账户菜单 → 数据备份：导出全部数据为 zip——账号、数字员工、聊天记录与附件文件（含头像），可离线保存或迁移
  • 导入数据：选择 zip → 系统自动检查账号（按用户名）与数字员工（按标识）是否存在，缺失的自动补齐，已存在的账号会更新资料（密码保留）
  • 导入时勾选要恢复的聊天记录知聚，消息发送者 / 提及引用自动重写，附件与头像一并还原
  • 初始化（清空一切）（危险操作，需输入「确认」）：删除全部数据并清空浏览器缓存，回到登录页；如需保留数据请先导出

  • 仅 @ 提及者可见：只有被 @ 的成员可见
  • 私聊：仅当前选中的成员（双击选中的 @ 对象）可见
