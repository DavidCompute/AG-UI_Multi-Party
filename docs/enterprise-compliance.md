# 企业合规：账号注销（数据擦除）与审计日志

> 适用代码版本：仓库 HEAD（2026-09 起）。Web 端已随部署推送生效；桌面版将在下一安装包发布时一并获得（Web / 桌面共用同一 Hub / 前端）。

## 一、账号注销与数据擦除（数据主体权利，PIPL / GDPR「删除权」第一刀）

### 入口

| 场景 | 入口 | 说明 |
| --- | --- | --- |
| 用户本人注销 | 「我的资料」弹窗 → ⚠️ 危险操作 → **注销账户**（`DELETE /ag-ui/account`） | 需输入**登录密码**确认（防会话劫持 / 误删） |
| 用户导出本人数据 | 「我的资料」弹窗 → ⚠️ 危险操作 → **⬇ 导出我的数据**（`GET /ag-ui/account/export`） | 注销前留存 / 迁移到新平台（见下节「个人数据导出」） |
| 管理员删除他人 | 管理员控制台 → 用户管理 → 每行 🗑️（`DELETE /ag-ui/admin/users/{userId}`） | 需先确认 + 输入该用户名二次核对；不可删除自己（本人请走自助注销） |

### 数据擦除语义（`AccountErasureService`，Web 编排，两端共用）

按顺序执行，全部成功才删除账号行；任一步骤失败则**保留账号（保持停用）**，便于管理员介入重试：

1. **账号即时停摆**：停用账号（阻止继续登录）+ 吊销全部会话令牌 + 终止该账号全部实时连接 + 清除 TOTP 密钥与限速状态；
2. **知聚处置**：
   - **其创建的知聚**：若存在其他**用户成员** → 群主**转让**给群管理员（否则最早加入的用户成员）并自行退群（保留其余成员与聊天历史）；若只剩本人 / 数字员工 → 整群**解散**（连同消息、语义记忆、图谱物理删除）；
   - **其加入的他人知聚**：自行**退群**（绝不触碰其他成员的发言、记忆与群本身）；
3. **语义记忆**：跨全部群按发送者（= 该用户）**物理删除**其发言的语义记忆（含向量）；
4. **个人知识库**：删除其创建的知识库（含文档向量与图谱隔离域）；
5. **账号行**：`IUserStore.RemoveUser` 删除（内存 / PostgreSQL / MySQL / SQLite / Redis 四种存储均已实现）。

### 安全防呆

- **最后一名超级管理员不可删除 / 不可注销**（防平台失去最高管理入口）；
- 管理员不能经管理接口删除自己（必须走自助注销的密码确认路径）；
- 注销成功后旧令牌即时失效（服务端吊销），前端自动清理本机桥连接与本地登录态回到登录页；
- 审计留痕：注销 / 删除都会记录 `user.account.delete`（操作者、目标、群处置 / 记忆 / 知识库数量、原因）。

### 本刀范围与刻意保留

- **保留**：他人群聊历史中该用户发送的**消息正文**（属共享群历史，删除会破坏他人会话语境）。如需彻底抹除，可使用既有「记忆治理 → 遗忘 / 删除」或由管理员在审计留痕前提下进一步介入。
- **保留**：该用户创建的**数字员工与技能定义**（可能仍被他人知聚引用，直接删除会造成悬空成员 / 悬空工具）；平台当前未自动清理此类目录项。
- **进程内状态**：`_supportCustomers`（客服知聚顾客参与）与 typing / 已读等瞬时状态不逐一清扫（有 TTL 自动回收 / 无害）。

## 二、个人数据导出（可携权）

「我的资料 → ⚠️ 危险操作 → ⬇ 导出我的数据」（`GET /ag-ui/account/export`，任意登录用户可点；需身份令牌）返回一个**只含本人数据**的 JSON 文件（`agui-my-data-<时间>.json`，UTF-8、camelCase、枚举字符串化、缩进易读），供注销前留存 / 迁移。内容包括：

- `account`：本人账号资料（昵称 / 头像 / 注册时间 / 生效平台角色等）；
- `groups`：本人所在（成员 / 群主）知聚清单（类型、我的角色、成员数、创建与最后活跃时间）；
- `messages`：本人**发言**（跨全部所在知聚；每群回溯最多 300 条、总量上限 3000；含附件元信息；已撤回只给标记不给正文）；
- `memories`：本人发言的**语义记忆**（记忆启用时，上限 2000 条）；
- `knowledgeBases`：本人创建的知识库元数据 + 文档清单（不含向量）；
- `agents` / `skills`：本人创建的数字员工与技能**完整定义**（可迁移到新平台）。

每次导出在审计日志记录 `data.export`（detail 含各类数量）。

## 三、审计日志检索与 CSV 导出

### 记录内容（`AuditLogService`，进程内环形缓冲，容量 5000，重启清空）

记录：人机审批决策、数据导出 / 导入、重置、模型 / 运维配置变更、管理员禁用 / 重置密码 / 删除账号、平台角色变更等关键 / 敏感操作。

### 查询

`GET /ag-ui/admin/audit`（管理员及以上，含运维）：

- 返回 `total`（缓冲总量）+ `entries`（按时间**倒序**，最多 200 条）；
- 过滤参数（均为可选，子串 / 区间匹配，不区分大小写）：
  - `actor` —— 操作者用户名 / userId 子串
  - `action` —— 操作名子串（如 `admin.user`、`user.account.delete`）
  - `targetId` —— 目标 ID 子串（如被删除用户的 userId）
  - `fromMs` / `toMs` —— UTC 毫秒时间范围（含端点）
  - `limit` —— 上限（默认 100，硬上限 200）

### CSV 导出

`GET /ag-ui/admin/audit.csv?…`（同查询过滤参数）：

- 导出**全部命中**记录（无 200 条上限；最多即缓冲容量 5000），按时间**正序**便于回溯；
- UTF-8 **BOM** + RFC 4180 转义（字段含逗号 / 引号 / 换行时加引号、内部引号双写），Excel 直接打开中文不乱码；
- 列：`id, timeUtc, timeMs, action, actorId, actorUsername, groupId, targetType, targetId, detail, result`。

### 前端

管理员控制台新增「**审计日志**」页签：按 操作者 / 操作名 / 目标 ID 过滤查询 + **⬇ 导出 CSV**（按当前过滤条件）。

## 五、已知限制与后续候选

- 审计当前为**进程内内存**存储，服务重启即清空；需要跨重启持久化的审计可后续接入数据库审计表；
- 头像 / 昵称在他人群历史中的**快照文本**（消息行冗余字段）不随注销改写；
- 个人数据导出不含：他人群历史里他人发言、**附件二进制**（仅有元信息；完整二进制请管理员走「数据备份 → 导出全部」）、知识库**向量内容**；
- 下一步候选：用户发言在他人群中的**内容抹除 / 匿名化**策略、注销前**导出个人数据**引导（当前「导出我的数据」与「注销账户」并排提供）、数字员工与技能目录的孤儿清理。
