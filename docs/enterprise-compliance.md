# 企业合规：账号注销（数据擦除）与审计日志

> 适用代码版本：仓库 HEAD（2026-09 起）。Web 端已随部署推送生效；桌面版将在下一安装包发布时一并获得（Web / 桌面共用同一 Hub / 前端）。

## 一、账号注销与数据擦除（数据主体权利，PIPL / GDPR「删除权」第一刀）

### 入口

| 场景 | 入口 | 说明 |
| --- | --- | --- |
| 用户本人注销 | 「我的资料」弹窗 → ⚠️ 危险操作 → **注销账户**（`DELETE /ag-ui/account`） | 需输入**登录密码**确认（防会话劫持 / 误删）；若 30 天以上未导出过个人数据（服务端审计判定，跨设备一致），弹窗会提示<b>先导出留存</b>并可一键先导出 |
| 用户导出本人数据 | 「我的资料」弹窗 → ⚠️ 危险操作 → **⬇ 导出我的数据**（`GET /ag-ui/account/export`） | 注销前留存 / 迁移到新平台（见下节「个人数据导出」）；`GET /ag-ui/account/export-guide` 供注销弹窗探测上次导出时间 |
| 管理员删除他人 | 管理员控制台 → 用户管理 → 每行 🗑️（`DELETE /ag-ui/admin/users/{userId}`） | 需先确认 + 输入该用户名二次核对；不可删除自己（本人请走自助注销） |
| 管理员孤儿盘点 | 管理员控制台 → **孤儿盘点**（`GET /ag-ui/admin/orphans`） | OwnerId 指向已注销账号的数字员工 / 技能清单：仍被引用的可**接管**到自己名下，未引用的可直接**删除** |

### 数据擦除语义（`AccountErasureService`，Web 编排，两端共用）

按顺序执行，全部成功才删除账号行；任一步骤失败则**保留账号（保持停用）**，便于管理员介入重试：

1. **账号即时停摆**：停用账号（阻止继续登录）+ 吊销全部会话令牌 + 终止该账号全部实时连接 + 清除 TOTP 密钥与限速状态；
2. **知聚处置**：
   - **其创建的知聚**：若存在其他**用户成员** → 群主**转让**给群管理员（否则最早加入的用户成员）并自行退群（保留其余成员与聊天历史）；若只剩本人 / 数字员工 → 整群**解散**（连同消息、语义记忆、图谱物理删除）；
   - **其加入的他人知聚**：自行**退群**（绝不触碰其他成员的发言、记忆与群本身）；
3. **语义记忆**：跨全部群按发送者（= 该用户）**物理删除**其发言的语义记忆（含向量）；
4. **个人知识库**：删除其创建的知识库（含文档向量与图谱隔离域）；
5. **现存群发言匿名化**：其在<b>仍保留的群</b>（转让群 / 他人群）中的消息做<b>内容匿名化</b>——正文清空、附件 / 提及 / 推理 / 技能链 / 计划清除、发送者昵称改「已注销用户」占位，但<b>保留消息行与时间线</b>（其余成员会话上下文不破坏，个人内容不再留存）；
6. **数字员工 / 技能孤儿清理**：其创建的、<b>不再被任何现存群引用</b>（成员身份 / 保留定义的中继、升级引用）的定义删除，并同步清理群内触发注册（含随解散知聚遗留的注册）；仍被他人知聚成员引用的定义<b>保留</b>（保证他人知聚功能不悬空）；
7. **账号行**：`IUserStore.RemoveUser` 删除（内存 / PostgreSQL / MySQL / SQLite / Redis 四种存储均已实现）。

### 安全防呆

- **最后一名超级管理员不可删除 / 不可注销**（防平台失去最高管理入口）；
- 管理员不能经管理接口删除自己（必须走自助注销的密码确认路径）；
- 注销成功后旧令牌即时失效（服务端吊销），前端自动清理本机桥连接与本地登录态回到登录页；
- 审计留痕：注销 / 删除都会记录 `user.account.delete`（操作者、目标、群处置 / 记忆 / 知识库数量、原因）。

### 本刀范围与刻意保留

- **保留**：他人群中<b>其余用户的发言</b>（匿名化只处理该用户自己的消息行）；该用户发言的<b>消息行与时间线位置</b>（匿名化处理，正文不残留）。
- **进程内状态**：`_supportCustomers`（客服知聚顾客参与）与 typing / 已读等瞬时状态不逐一清扫（有 TTL 自动回收 / 无害）。
- **数字员工 / 技能**：仍被现存群成员 / 保留定义引用的<b>保留</b>（防他人知聚悬空）；未被引用的随注销清理。

### 审计持久化

操作审计日志采用<b>独立表存储</b>（`IAuditStore` → PostgreSQL / MySQL / SQLite 的 <c>agui_audit</c> 表）：写入、检索 / 导出、保留裁剪全走 SQL，**服务重启 / 复制实例间天然保留与一致**；
统一保留策略 <b>5000 条</b>（每 256 次写入周期裁剪最旧）。memory / Redis 模式回退为进程内环形缓冲 + 扩展区快照持久化（`RegisterAuditPersistence` 检测到独立表时自动跳过扩展区，避免双写）。

## 二、个人数据导出（可携权）

「我的资料 → ⚠️ 危险操作 → ⬇ 导出我的数据」（`GET /ag-ui/account/export`，任意登录用户可点；需身份令牌）返回一个**只含本人数据**的 JSON 文件（`agui-my-data-<时间>.json`，UTF-8、camelCase、枚举字符串化、缩进易读），供注销前留存 / 迁移。内容包括：

- `account`：本人账号资料（昵称 / 头像 / 注册时间 / 生效平台角色等）；
- `groups`：本人所在（成员 / 群主）知聚清单（类型、我的角色、成员数、创建与最后活跃时间）；
- `messages`：本人**发言**（跨全部所在知聚；每群回溯最多 300 条、总量上限 3000；含附件元信息；已撤回只给标记不给正文）；
- `memories`：本人发言的**语义记忆**（记忆启用时，上限 2000 条）；
- `knowledgeBases`：本人创建的知识库元数据 + 文档清单（不含向量）；
- `agents` / `skills`：本人创建的数字员工与技能**完整定义**（可迁移到新平台）。

每次导出在审计日志记录 `data.export`（detail 含各类数量）。注销弹窗打开时会经 `GET /ag-ui/account/export-guide`（取本人最近一次 `data.export` 审计）判断是否需要<b>先导出引导</b>。

### 孤儿定义运营盘点（管理员）

`GET /ag-ui/admin/orphans` 列出 OwnerId 指向已注销账号的数字员工 / 技能，并给出<b>引用上下文</b>（作为哪些现存知聚成员、被哪些现存定义中继 / 升级引用、被哪些数字员工挂载）。

- `POST /ag-ui/admin/orphans/agents/{agentId}/adopt` 与 `POST /ag-ui/admin/orphans/skills/{skillId}/adopt`：把孤儿定义<b>接管到当前管理员</b>名下（之后可常规编辑 / 挂载 / 迁移）；
- `DELETE /ag-ui/admin/orphans/agents/{agentId}`、`DELETE /ag-ui/admin/orphans/skills/{skillId}`：删除孤儿定义，带<b>安全闸</b>——仍被现存知聚成员或现存定义引用的返回 403（防止悬空），未引用的历史遗留可直接删除；
- 管理员控制台新增「孤儿盘点」页签承载以上能力。

## 三、审计日志检索与 CSV 导出

### 记录内容（`AuditLogService` 环形缓冲 / 独立表，保留策略 5000 条，超量裁剪最旧）

记录：人机审批决策、数据导出 / 导入、重置、模型 / 运维配置变更、管理员禁用 / 重置密码 / 删除账号、平台角色变更等关键 / 敏感操作。**数据库模式为独立表 `agui_audit`（跨重启保留），memory / Redis 为持久化扩展区。**

### 查询

`GET /ag-ui/admin/audit`（管理员及以上，含运维）：

- 返回 `total`（缓冲总量）+ `entries`（按时间**倒序**，最多 200 条）；
- 过滤参数（均为可选，子串 / 区间匹配，不区分大小写）：
  - `actor` —— 操作者用户名 / userId 子串
  - `action` —— 操作名子串（如 `admin.user`、`user.account.delete`）
  - `targetId` —— 目标 ID 子串（如被删除用户的 userId）
  - `fromMs` / `toMs` —— UTC 毫秒时间范围（含端点）
  - `limit` —— 上限（默认 100，硬上限 200）

### CSV 导出

`GET /ag-ui/admin/audit.csv?…`（同查询过滤参数）：

- 导出**全部命中**记录（无 200 条上限；最多即缓冲容量 5000），按时间**正序**便于回溯；
- UTF-8 **BOM** + RFC 4180 转义（字段含逗号 / 引号 / 换行时加引号、内部引号双写），Excel 直接打开中文不乱码；
- 列：`id, timeUtc, timeMs, action, actorId, actorUsername, groupId, targetType, targetId, detail, result`。

### 前端

管理员控制台新增「**审计日志**」页签：按 操作者 / 操作名 / 目标 ID 过滤查询 + **⬇ 导出 CSV**（按当前过滤条件）。

## 五、已知限制与后续候选

- 头像 / 昵称在他人群历史中的**快照文本**已随匿名化改写为「已注销用户」占位，不再随注销保留真实显示名；
- 个人数据导出不含：他人群历史里他人发言、**附件二进制**（仅有元信息；完整二进制请管理员走「数据备份 → 导出全部」）、知识库**向量内容**；
- 下一步候选：注销前**导出引导**增强、数字员工孤儿定义与被保留定义的**运营盘点界面**。
